El siguiente TXT debe ser leído sin saltarse nada ni obviar absolutamente nada
tampoco saltarse delimitadores XML por precaución de romper algo.

¿TENDRÁ EMOJIS EL FRONTEND?
Ninguno, el proyecto Opti busca seriedad porque estamos por la plata no por la patria.

¿QUÉ LIBRERÍAS ESTAMOS USANDO?
🌟Leaflet.js (v1.9.4)
Es la librería estándar open-source para mapas interactivos ligeros (~40 KB). 
Se integra nativamente con los azulejos (tiles) gratuitos de OpenStreetMap.   

🌟Bootstrap (v5.3)
Proporciona el sistema de rejilla (grid flexbox), el comportamiento mobile-first, 
la gestión de modales de autenticación y los componentes base de la plantilla Made.   

🌟FontAwesome (v6.5)
Aporta la iconografía vectorial para herramientas ferreteras 
(martillos, llaves, pines de ubicación, stock, candados) sin sobrecargar 
la red cargando imágenes .png individuales.

<RESPONSIVE_MOBILE_FIRST>
* Viewport Móvil: En pantallas < 768px, el mapa de Leaflet.js ocupa el 100% del viewport vertical (100vh).
* Buscador Flotante (Google Maps / Trufi UX): El cuadro de búsqueda de origen/producto flota sobre el mapa en la parte superior con z-index elevado y sombras suaves.
* Tablas Adaptables: En dispositivos móviles, las tablas de datos (CRUD e Inventarios) cambian dinámicamente a tarjetas desglosables (Responsive Cards) para evitar el desplazamiento horizontal incómodo.
</RESPONSIVE_MOBILE_FIRST>

<COMPORTAMIENTO_TEMA_TOGGLE>
* Mecanismo: Elemento HTML con id="themeToggle" que ejecuta JavaScript para alternar el atributo `data-theme` en el tag <html>.
* Persistencia: Utiliza `localStorage.getItem('iop812-theme')` para recordar la preferencia del usuario entre sesiones.
</COMPORTAMIENTO_TEMA_TOGGLE>

<REGLAS_ESPACIALES_GOOGLE_MAPS_V1_1>
1. LIENZO FULL-BLEED (100dvh):
   - Se suprime la barra de navegación superior tradicional (<nav id="topNav">).
   - El contenedor #mapa-ahp y #map ocupan el 100% del viewport (width: 100vw; height: 100dvh; overflow: hidden).
   - html, body mantienen overflow-x: hidden estricto; SweetAlert2 opera con .swal2-container { z-index: 2050 !important; }.

2. OMNIBOX FLOTANTE SUPERIOR IZQUIERDO (top: 16px; left: 16px; z-index: 1010):
   - Dimensiones: 376px de ancho x 48px de alto en escritorio; calc(100vw - 84px) x 48px en móvil (< 768px).
   - Estructura horizontal interna (flex-nowrap, border-radius: 24px, var(--card-bg), sombra elevada):
     [Botón Menú Lateral (fa-bars)] | [Input directo de producto] | [Botón Buscar (fa-magnifying-glass)] | [Botón Pesos AHP (fa-sliders)]
   - Debajo del Omnibox se despliega de forma colapsable:
     a) Fila compacta de Origen + botón GPS (fa-crosshairs) + badge de consistencia CR < 0.10.
     b) Panel de sliders Saaty (Precio, Cercanía, Reputación, Stock) al pulsar fa-sliders.

3. ESFÉRICO DE PERFIL Y CONTROLES SUPERIORES DERECHOS (top: 16px; right: 16px; z-index: 1010):
   - Botón Esférico de Cuenta (40px x 40px, border-radius: 50%):
     * Sin sesión: ícono fa-user; al pulsar abre #modalLoginAuth.
     * Con sesión: inicial del usuario en negrita; al pulsar despliega Popover flotante de cuenta (#popoverPerfilCuenta) con nombre, correo, badge de rol (CLIENTE / FERRETERO / ADMIN), botón de tema (Oscuro/Claro), acceso a Panel I.O. (si aplica) y botón Cerrar Sesión.
   - Botón Esférico de Tema (40px x 40px) accesible en todo momento.

4. VISOR DE ZOOM DE IMAGEN DE PRODUCTO (LIGHTBOX):
   - Dentro de #modalDetalleProducto, la fotografía cargada desde Cloudinary permite clic para alternar escala (1x -> 2x con arrastre/desplazamiento) o abrir vista ampliada a pantalla completa (#modalZoomImagen) con controles [fa-magnifying-glass-plus], [fa-magnifying-glass-minus] y [fa-xmark].
</REGLAS_ESPACIALES_GOOGLE_MAPS_V1_1>
