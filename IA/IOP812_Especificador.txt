¿QUÉ HACE LA APLICACIÓN?
Es una aplicación web geoespacial que busca la ferretería con la mejor combinación
de precio en bolivianos (BOB), cercanía, reputación y stock en la Región Metropolitana
Kanata de Cochabamba, Bolivia (Cercado, Sacaba, Quillacollo, Colcapirhua, Tiquipaya,
Vinto y Sipe Sipe), aplicando los modelos matemáticos de Investigación Operativa II (IOP812).

¿QUÉ FUNCIONALIDADES TIENE LA V1?
* Registro e inicio de sesión mediante Google OAuth 2.0 (Authorization Code Flow con estado
  anti-CSRF firmado y callback en servidor) y credenciales locales (PBKDF2-HMAC-SHA256 + JWT).
* Control de acceso basado en roles (cliente, ferretero, admin):
  - cliente: búsqueda geoespacial AHP, historial de búsquedas persistente, ferreterías
    favoritas y registro de su propia ferretería marcando coordenadas directamente en el mapa.
  - ferretero: gestión CRUD de su catálogo por sucursal, precios BOB, parámetros EOQ/ROP,
    carga masiva CSV de inventario y calculadoras de Investigación Operativa II.
  - admin / desarrollador: panel global de gestión de roles y funcionalidad exclusiva de
    ingesta masiva CSV (importación directa de ferreterías reales desde Overpass Turbo/OSM
    y carga masiva de catálogos multi-sucursal).
    Mediante:
    [out:csv(::id, name, "addr:street", "addr:city", ::lat, ::lon; true; ",")][timeout:25];

* Buscador geoespacial PostGIS (ST_DistanceSphere) y ordenamiento multicriterio AHP
  (Precio, Distancia, Reputación, Stock) con validación de consistencia CR < 0.10.
* Módulo de gestión de inventarios determinísticos (EOQ Básico, EPQ, EOQ con Faltantes,
  Descuentos por Cantidad y Punto de Reorden ROP).
* Módulo de Evaluación de Decisiones bajo Incertidumbre (Laplace, Wald Optimista/Pesimista,
  Hurwicz, Savage) y Riesgo (VME, VEconIP, VEIP).
* Módulo de Predicción mediante Cadenas de Markov con Estados Absorbentes (Matriz
  Fundamental N = (I - Q)^-1, Matriz de Absorción B = N*R y pasos esperados t).
* Estimación de tiempos de espera en mostrador mediante Teoría de Colas (Modelo M/M/1).

¿MÉTODOS DE INVESTIGACIÓN OPERATIVA II APLICADOS?
1. AHP (Analytic Hierarchy Process): Matriz de comparación por pares, vector de pesos W y ratio de consistencia CR = CI / RI < 0.10.
2. Modelos de Inventarios Determinísticos:
   - EOQ Básico: Q* = sqrt((2*D*K)/H)
   - EPQ (Producción): Q* = sqrt((2*D*K)/(H*(1 - D/P)))
   - EOQ Faltantes: S* = Q* * (H/(p+H)) y Q* ajustado por penalización p.
   - EOQ Descuentos: Evaluación de costo total CT por tramos de cantidad.
   - ROP (Punto de Reorden): ROP = (d * L) + SS.
3. Decisiones Bajo Incertidumbre: Laplace, Wald (Optimista/Pesimista), Hurwicz (alpha) y Savage (Matriz de arrepentimiento).
4. Decisiones Bajo Riesgo: Valor Medio Esperado VME = sum(P_j * V_j), VEconIP y VEIP.
5. Cadenas de Markov Absorbentes: Matriz fundamental N = (I - Q)^-1 y Matriz de Absorción B = N * R.
6. Teoría de Colas (M/M/1): Uso rho = lambda/mu, L, Lq, W, Wq = lambda / (mu * (mu - lambda)) y P0 = 1 - rho.

REGLAS DE NEGOCIO DEL SISTEMA:
1. Ordenamiento AHP: Valida que la matriz de comparación entre Precio, Distancia, Reputación y Stock cumpla CR = CI / RI < 0.10 para asegurar consistencia en la decisión.
2. Gestión de Inventarios:
   - Aplica EOQ para productos comprados y EPQ para productos de fabricación propia en ferreterías.
   - En productos con volumen con descuento, calcula el costo total (CT) en cada tramo para determinar el lote óptimo real.
   - Notifica punto de reorden en tiempo real según ROP = (d * L) + SS.
3. Decisiones Financieras / Suministro:
   - Si no hay probabilidades conocidas, presenta la sugerencia según Laplace, Wald, Hurwicz (alpha=0.7) y Savage.
   - Con probabilidades estimadas, sugiere la alternativa que maximice el VME.
4. Cadenas de Markov:
   - Calcula la matriz fundamental N y la matriz de absorción B para estimar la tasa probable de conversión a venta.
5. Tiempos de Espera (Colas M/M/1):
   - Muestra el tiempo estimado de espera en mostrador Wq para recomendar el mejor momento de visita presencial.
6. Base Limpia Sin Datos Ficticios:
   - La inicialización de la base de datos crea únicamente el esquema PostgreSQL/PostGIS; toda la población inicial de ferreterías y catálogos se realiza mediante las herramientas exclusivas de Desarrollador/Admin en CSV real.

2. REGLAS DE NEGOCIO Y FLUJO DE USUARIO (RN-07 a RN-11)
* RN-07 (Interfaz Espacial Omnibox + Esférico de Cuenta):
  - El usuario escribe directamente en el Omnibox (`376px x 48px` desktop / `calc(100vw - 84px) x 48px` móvil) sin desplegar tarjetas previas. El botón de filtros AHP despliega los pesos Saaty debajo del Omnibox.
  - El botón esférico superior derecho (`40px x 40px`) gestiona inicio de sesión o despliega el Popover de perfil con rol, cambio de tema y cierre de sesión accesible en cualquier resolución.
* RN-08 (Favoritos Reactivos y Modal de Ferretería con Catálogo Completo):
  - El frontend mantiene sincronizados los `id_ferreteria` favoritos del usuario: si una tienda ya es favorita, el botón muestra estado activo ("Quitar de Favoritos", `DELETE /api/ahp/favoritos/{id}`).
  - Al presionar una ferretería en la pestaña **Favoritos** del Drawer lateral, se cierra el Drawer, el mapa centra la cámara (`flyTo`) en sus coordenadas y se abre el **Modal de Ficha de Ferretería** (`#modalDetalleFerreteria`), el cual muestra su dirección, reputación, tiempo de espera en cola ($W_q$), botón para trazar ruta y un botón **"Ver Catálogo Completo"** (`GET /api/ahp/ferreterias/{id_ferreteria}/catalogo`) que lista todos sus productos con precio en BOB, stock disponible y acceso a su ficha individual.
  - El **Historial** restaura término buscado + coordenadas (`latitud_usuario`, `longitud_usuario`) y permite borrar registros individuales (`DELETE /api/ahp/historial/{id_busqueda}`).
* RN-09 (Tiempo de Espera M/M/1 en Resultados Cliente):
  - Al calcular métricas en el tab Colas M/M/1 del panel ferretero, los parámetros ($\lambda, \mu$) se persisten en `registro_colas_atencion` asociados a `id_ferreteria`.
  - `POST /api/ahp/buscar` consulta el último registro M/M/1 de cada ferretería candidata y retorna `tiempo_espera_wq_min` y estado de congestión en las tarjetas y popups.
* RN-10 (Enrutamiento Multi-Modo y Tiempo Logístico Total):
  - Endpoint `GET /api/ahp/ruta?origen_lat=...&origen_lng=...&destino_lat=...&destino_lng=...&modo=...` consulta OpenRouteService y retorna ruta principal y alternativas en GeoJSON.
  - El mapa traza la ruta principal en azul sólido (`#0EA5E9`) y las alternativas en gris punteado (`#94A3B8`) seleccionables al clic. La tarjeta de navegación calcula: `Tiempo de viaje + Espera en cola (Wq) = Tiempo total estimado`.
* RN-11 (Ficha Técnica de Producto y Zoom de Imagen):
  - Al pulsar cualquier producto (desde resultados AHP, popup del mapa o catálogo de una ferretería), se abre `#modalDetalleProducto` mostrando fotografía desde Cloudinary, nombre, marca, categoría, descripción técnica, precio en BOB, stock actual y botón **"Cómo llegar a esta ferretería"**.
  - Al hacer clic sobre la imagen del producto (o en el botón de lupa `fa-magnifying-glass-plus`), se activa el visor con zoom interactivo (`#modalZoomImagen` / zoom 2x con desplazamiento) para inspeccionar detalles del material o herramienta.

def _obtener_lista_admins() -> List[str]:
    raw_admins = os.getenv("ADMIN_EMAILS") or os.getenv("ADMIN_EMAIL") or ""
    return [e.strip().lower() for e in raw_admins.split(",") if e.strip()]


def _determinar_rol_inicial(cur, email: str) -> str:
    admin_emails = _obtener_lista_admins()
    if admin_emails:
        return "admin" if email.strip().lower() in admin_emails else "cliente"

    cur.execute("SELECT COUNT(*) AS total FROM usuarios WHERE rol = 'admin';")
    if cur.fetchone()["total"] == 0:
        return "admin"
    return "cliente"


def obtener_usuario_actual(credentials: HTTPAuthorizationCredentials = Depends(security)) -> Dict[str, Any]:
    token = credentials.credentials
    payload = decodificar_access_token(token)
    if not payload:
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Token de acceso inválido o expirado. Inicie sesión nuevamente."
        )

    email = payload.get("sub")
    conn = obtener_conexion()
    try:
        with conn.cursor() as cur:
            cur.execute(
                """
                SELECT u.id_usuario, u.email, u.username, COALESCE(u.rol, 'cliente') AS rol,
                       u.google_id, u.fecha_registro,
                       f.id_ferreteria, f.nombre AS nombre_ferreteria
                FROM usuarios u
                LEFT JOIN ferreterias f ON f.id_usuario_propietario = u.id_usuario
                WHERE u.email = %s
                LIMIT 1;
                """,
                (email,)
            )
            usuario = cur.fetchone()
            if not usuario:
                raise HTTPException(status_code=status.HTTP_404_NOT_FOUND, detail="Usuario no encontrado.")
            return dict(usuario)
    finally:
        conn.close()


def obtener_usuario_opcional(
    credentials: Optional[HTTPAuthorizationCredentials] = Depends(security_opcional)
) -> Optional[Dict[str, Any]]:
    if not credentials:
        return None
    try:
        return obtener_usuario_actual(credentials)
    except HTTPException:
        return None


def requerir_admin(usuario: Dict[str, Any] = Depends(obtener_usuario_actual)) -> Dict[str, Any]:
    if usuario.get("rol") != "admin":
        raise HTTPException(
            status_code=status.HTTP_403_FORBIDDEN,
            detail="Acceso restringido a administradores del sistema."
        )
    return usuario

@router.post("/registro", response_model=TokenOutput, status_code=status.HTTP_201_CREATED)
async def registrar_usuario(datos: UsuarioRegistroInput):
    password_hash = generar_salt_y_hash(datos.password)
    conn = obtener_conexion()
    try:
        with conn.cursor() as cur:
            cur.execute("SELECT id_usuario FROM usuarios WHERE email = %s;", (datos.email,))
            if cur.fetchone():
                raise HTTPException(status_code=400, detail="El correo electrónico ya se encuentra registrado.")

            rol = _determinar_rol_inicial(cur, datos.email)
            cur.execute(
                """
                INSERT INTO usuarios (email, username, password_hash, rol)
                VALUES (%s, %s, %s, %s)
                RETURNING id_usuario, rol;
                """,
                (datos.email, datos.username, password_hash, rol)
            )
            nuevo = cur.fetchone()
            conn.commit()

        token = crear_access_token({"sub": datos.email, "username": datos.username, "rol": nuevo["rol"]})
        return {
            "access_token": token,
            "token_type": "bearer",
            "username": datos.username,
            "email": datos.email,
            "rol": nuevo["rol"]
        }
    except HTTPException:
        conn.rollback()
        raise
    except Exception as e:
        conn.rollback()
        raise HTTPException(status_code=500, detail=f"Error en base de datos: {str(e)}")
    finally:
        conn.close()


@router.post("/login", response_model=TokenOutput, status_code=status.HTTP_200_OK, summary="Login con correo y contraseña")
async def login_usuario(datos: UsuarioLoginInput):
    conn = obtener_conexion()
    try:
        with conn.cursor() as cur:
            cur.execute(
                """
                SELECT id_usuario, email, username, password_hash, COALESCE(rol, 'cliente') AS rol
                FROM usuarios WHERE email = %s;
                """,
                (datos.email,)
            )
            usuario = cur.fetchone()
            if not usuario or not usuario["password_hash"] or not verificar_password(datos.password, usuario["password_hash"]):
                raise HTTPException(
                    status_code=status.HTTP_401_UNAUTHORIZED,
                    detail="Credenciales incorrectas.")

        token = crear_access_token({"sub": usuario["email"], "username": usuario["username"], "rol": usuario["rol"]})
        return {
            "access_token": token,
            "token_type": "bearer",
            "username": usuario["username"],
            "email": usuario["email"],
            "rol": usuario["rol"]
        }
    finally:
        conn.close()

def _autenticar_o_crear_usuario_google(google_info: Dict[str, Any]) -> Dict[str, Any]:
    google_id = google_info.get("sub")
    email = google_info.get("email")
    if not email or not google_id:
        raise HTTPException(
            status_code=status.HTTP_400_BAD_REQUEST,
            detail="El token de Google no contiene un correo electrónico o ID de usuario válido."
        )

    nombre_google = google_info.get("name") or email.split("@")[0]
    username_base = nombre_google.replace(" ", "_").lower()[:40]

    conn = obtener_conexion()
    try:
        with conn.cursor() as cur:
            cur.execute(
                """
                SELECT id_usuario, email, username, google_id, COALESCE(rol, 'cliente') AS rol
                FROM usuarios WHERE google_id = %s OR email = %s;
                """,
                (google_id, email)
            )
            usuario = cur.fetchone()

            if not usuario:
                cur.execute("SELECT id_usuario FROM usuarios WHERE username = %s;", (username_base,))
                username_final = f"{username_base}_{google_id[:5]}" if cur.fetchone() else username_base
                rol = _determinar_rol_inicial(cur, email)

                cur.execute(
                    """
                    INSERT INTO usuarios (email, username, google_id, password_hash, rol)
                    VALUES (%s, %s, %s, NULL, %s)
                    RETURNING id_usuario, email, username, rol;
                    """,
                    (email, username_final, google_id, rol)
                )
                conn.commit()
                usuario_db = cur.fetchone()
                username_actual, email_actual, rol_actual = usuario_db["username"], usuario_db["email"], usuario_db["rol"]
            else:
                if not usuario["google_id"]:
                    cur.execute("UPDATE usuarios SET google_id = %s WHERE id_usuario = %s;", (google_id, usuario["id_usuario"]))
                    conn.commit()
                username_actual, email_actual, rol_actual = usuario["username"], usuario["email"], usuario["rol"]

        token = crear_access_token({"sub": email_actual, "username": username_actual, "rol": rol_actual})
        return {
            "access_token": token,
            "token_type": "bearer",
            "username": username_actual,
            "email": email_actual,
            "rol": rol_actual
        }
    except HTTPException:
        conn.rollback()
        raise
    except Exception as e:
        conn.rollback()
        raise HTTPException(
            status_code=status.HTTP_500_INTERNAL_SERVER_ERROR,
            detail=f"Error en base de datos al autenticar con Google: {str(e)}"
        )
    finally:
        conn.close()


def _resolver_google_redirect_uri(request: Request) -> str:
    if GOOGLE_REDIRECT_URI:

@router.post("/ferreterias/carga-masiva", summary="Carga masiva CSV de ferreterías reales (Solo Admin/Desarrollador)")
async def carga_masiva_ferreterias_admin(
    archivo: UploadFile = File(...),
    admin: Dict[str, Any] = Depends(requerir_admin)
):
    """
    Acepta directamente el CSV exportado desde Overpass Turbo:
      @id,name,addr:street,addr:city,@lat,@lon
    o el formato estándar:
      nombre,direccion,latitud,longitud,reputacion,superficie_almacen_m2,capacidad_canales_atencion
    """
    contenido = await archivo.read()
    texto = contenido.decode("utf-8-sig", errors="replace")
    lineas = texto.splitlines()
    if not lineas:
        raise HTTPException(status_code=400, detail="El archivo CSV está vacío.")

    delimitador = ";" if ";" in lineas[0] else ","
    lector = csv.DictReader(io.StringIO(texto), delimiter=delimitador)

    conn = obtener_conexion()
    insertadas = 0
    actualizadas = 0
    omitidas = 0
    errores = []

    def _limpiar_campo(val: Optional[str]) -> str:
        if not val:
            return ""
        limpio = val.strip()
        return "" if limpio.lower() == "null" else limpio

    try:
        with conn.cursor() as cur:
            for num_fila, fila in enumerate(lector, start=2):
                try:
                    nombre = _limpiar_campo(fila.get("nombre") or fila.get("name"))
                    if not nombre:
                        omitidas += 1
                        continue

                    raw_lat = _limpiar_campo(fila.get("latitud") or fila.get("@lat"))
                    raw_lon = _limpiar_campo(fila.get("longitud") or fila.get("@lon"))
                    if not raw_lat or not raw_lon:
                        omitidas += 1
                        continue

                    latitud = float(raw_lat)
                    longitud = float(raw_lon)

                    direccion = _limpiar_campo(fila.get("direccion"))
                    if not direccion:
                        calle = _limpiar_campo(fila.get("addr:street"))
                        ciudad = _limpiar_campo(fila.get("addr:city"))
                        partes = [p for p in (calle, ciudad) if p]
                        direccion = ", ".join(partes) if partes else "Región Metropolitana Kanata, Cochabamba"

                    reputacion = float(_limpiar_campo(fila.get("reputacion")) or 4.5)
                    superficie = float(_limpiar_campo(fila.get("superficie_almacen_m2")) or 120.0)
                    canales = int(float(_limpiar_campo(fila.get("capacidad_canales_atencion")) or 1))

                    # Evitar duplicados por nombre y cercanía (< ~50m)
                    cur.execute(
                        """
                        SELECT id_ferreteria FROM ferreterias
                        WHERE LOWER(nombre) = LOWER(%s)
                          AND ABS(latitud - %s) < 0.0005
                          AND ABS(longitud - %s) < 0.0005
                        LIMIT 1;
                        """,
                        (nombre, latitud, longitud)
                    )
                    existente = cur.fetchone()

                    if existente:
                        cur.execute(
                            """
                            UPDATE ferreterias
                            SET direccion = %s, latitud = %s, longitud = %s,
                                ubicacion = ST_SetSRID(ST_MakePoint(%s, %s), 4326),
                                reputacion = %s, superficie_almacen_m2 = %s,
                                capacidad_canales_atencion = %s
                            WHERE id_ferreteria = %s;
                            """,

    except Exception as e:

if not ALGORITHM:

if not raw_expire:
    raise ValueError("Error de configuración: La variable 'ACCESS_TOKEN_EXPIRE_HOURS' es requerida en el archivo .env")

GOOGLE_REDIRECT_URI = os.getenv("GOOGLE_REDIRECT_URI", "").strip()

def generar_salt_y_hash(password: str) -> str:
    """Genera un hash seguro utilizando PBKDF2-HMAC-SHA256 con sal aleatoria de 16 bytes."""
    salt = secrets.token_bytes(16)
    hash_bytes = hashlib.pbkdf2_hmac("sha256", password.encode("utf-8"), salt, 100_000)
    return f"{salt.hex()}:{hash_bytes.hex()}"


def verificar_password(password_plana: str, password_almacenado: str) -> bool:
    """Verifica si la contraseña dada coincide con la sal y hash guardados."""
    try:
        salt_hex, hash_hex = password_almacenado.split(":")
        salt = bytes.fromhex(salt_hex)
        hash_calculado = hashlib.pbkdf2_hmac("sha256", password_plana.encode("utf-8"), salt, 100_000)
        return secrets.compare_digest(hash_calculado.hex(), hash_hex)
    except Exception as exc:
        logger.warning("Fallo al verificar el hash de contraseña: %s", exc)
        return False


def crear_access_token(data: Dict[str, Any], expira_horas: int = ACCESS_TOKEN_EXPIRE_HOURS) -> str:
    """Firma un token de acceso JWT con vigencia programada."""
    payload = data.copy()
    expiracion = datetime.now(timezone.utc) + timedelta(hours=expira_horas)
    payload.update({"exp": expiracion})
    return jwt.encode(payload, SECRET_KEY, algorithm=ALGORITHM)


def decodificar_access_token(token: str) -> Optional[Dict[str, Any]]:
    """Valida la autenticidad y vigencia del JWT."""
    try:
        return jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
    except jwt.ExpiredSignatureError as exc:
        logger.warning("El token de acceso ha expirado: %s", exc)
        return None
    except jwt.InvalidTokenError as exc:
        logger.warning("El token de acceso no es válido: %s", exc)
        return None


def verificar_token_google(credential_token: str) -> Optional[Dict[str, Any]]:
    """Verifica la firma del ID Token recibido de Google Identity Services."""
    try:
        request_adapter = requests.Request()
        if GOOGLE_CLIENT_ID and GOOGLE_CLIENT_ID != "TU_GOOGLE_CLIENT_ID.apps.googleusercontent.com":
            id_info = id_token.verify_oauth2_token(credential_token, request_adapter, GOOGLE_CLIENT_ID)
        else:
            # Si no hay Client ID real en .env, valida la firma con los certificados públicos de Google
            id_info = id_token.verify_oauth2_token(credential_token, request_adapter)
        return id_info
    except Exception as e:
        logger.warning("Error verificando token de Google: %s", e)
        return None
def generar_estado_oauth() -> str:
    """Genera un token state firmado (JWT de 10 min) para protección anti-CSRF en OAuth2."""
    expiracion = datetime.now(timezone.utc) + timedelta(minutes=10)
    payload = {
        "purpose": "google_oauth_state",
        "nonce": secrets.token_urlsafe(16),
        "exp": expiracion
    }
    return jwt.encode(payload, SECRET_KEY, algorithm=ALGORITHM)


def validar_estado_oauth(state: str) -> bool:
    """Valida la firma y vigencia del parámetro state devuelto por Google."""
    try:
        payload = jwt.decode(state, SECRET_KEY, algorithms=[ALGORITHM])
        return payload.get("purpose") == "google_oauth_state"
    except Exception as exc:
        logger.warning("Estado OAuth2 inválido o expirado: %s", exc)
        return False


def intercambiar_codigo_google(code: str, redirect_uri: str) -> Optional[Dict[str, Any]]:
    """Intercambia el authorization code de Google por tokens y valida el id_token."""
    if not GOOGLE_CLIENT_ID or not GOOGLE_CLIENT_SECRET:
        logger.error("Faltan GOOGLE_CLIENT_ID o GOOGLE_CLIENT_SECRET en .env")
        return None

    try:
        resp = http_requests.post(
            "https://oauth2.googleapis.com/token",
            data={
                "code": code,
                "client_id": GOOGLE_CLIENT_ID,
                "client_secret": GOOGLE_CLIENT_SECRET,
                "redirect_uri": redirect_uri,
                "grant_type": "authorization_code"
            },
            timeout=10
        )
        if resp.status_code != 200:
            logger.warning("Error intercambiando código OAuth2 con Google (%s): %s", resp.status_code, resp.text)
            return None

        token_data = resp.json()
        raw_id_token = token_data.get("id_token")
        if not raw_id_token:
            return None

        return verificar_token_google(raw_id_token)
    except Exception as exc:
        logger.warning("Excepción en intercambio OAuth2 con Google: %s", exc)
        return None

        matriz = [[float(v[i] / v[j]) for j in range(n)] for i in range(n)]

        entrada_ahp = AHPMatrizCriteriosInput(
            criterios=["Precio", "Distancia", "Reputación", "Stock"],
            matriz_comparacion=matriz
        )
        # 2. Calcular consistencia matemática (NumPy)
        res_math = calcular_proceso_ahp(entrada_ahp)

        # 3. Consulta Geoespacial a PostgreSQL con PostGIS
        ferreterias_ordenadas = []
        conn = obtener_conexion()
        try:
            with conn.cursor() as cur:
                # Registrar en historial si el usuario está autenticado
                if usuario:
                    cur.execute(
                        """
                        INSERT INTO historial_busquedas (id_usuario, texto_buscado, latitud_usuario, longitud_usuario)
                        VALUES (%s, %s, %s, %s);
                        """,
                        (usuario["id_usuario"], datos.producto.strip(), datos.latitud, datos.longitud)
                    )
                    conn.commit()

                sql = """
                    SELECT 
                        f.id_ferreteria, f.nombre, f.direccion, f.latitud, f.longitud,
                        p.precio_bob, p.stock_actual, f.reputacion,
                        (ST_DistanceSphere(
                            COALESCE(f.ubicacion, ST_SetSRID(ST_MakePoint(f.longitud, f.latitud), 4326)),
                            ST_SetSRID(ST_MakePoint(%s, %s), 4326)
                        ) / 1000.0) AS distancia_km
                    FROM ferreterias f
                    JOIN productos p ON f.id_ferreteria = p.id_ferreteria
                    WHERE LOWER(p.nombre) LIKE LOWER(%s) AND p.stock_actual > 0
                    LIMIT 25;
                """
                cur.execute(sql, (datos.longitud, datos.latitud, f"%{datos.producto}%"))
                filas = cur.fetchall()

                if filas:
                    # Lectura con llaves de RealDictCursor
                    precios = [float(f["precio_bob"]) for f in filas]
                    distancias = [float(f["distancia_km"]) for f in filas]
                    reputaciones = [float(f["reputacion"]) for f in filas]
                    stocks = [int(f["stock_actual"]) for f in filas]

                    max_p, min_p = max(precios) or 1.0, min(precios) or 0.0
                    max_d, min_d = max(distancias) or 1.0, min(distancias) or 0.0
                    max_r, min_r = max(reputaciones) or 5.0, min(reputaciones) or 1.0
                    max_s, min_s = max(stocks) or 1, min(stocks) or 0

                    w_precio = res_math["vector_pesos_W"]["Precio"] / 100.0
                    w_dist = res_math["vector_pesos_W"]["Distancia"] / 100.0
                    w_rep = res_math["vector_pesos_W"]["Reputación"] / 100.0
                    w_stock = res_math["vector_pesos_W"]["Stock"] / 100.0

                    for f in filas:
                        norm_precio = (max_p - float(f["precio_bob"])) / (max_p - min_p) if max_p != min_p else 1.0
                        norm_dist = (max_d - float(f["distancia_km"])) / (max_d - min_d) if max_d != min_d else 1.0
                        norm_rep = (float(f["reputacion"]) - min_r) / (max_r - min_r) if max_r != min_r else 1.0
                        norm_stock = (int(f["stock_actual"]) - min_s) / (max_s - min_s) if max_s != min_s else 1.0

                        score_total = (norm_precio * w_precio) + (norm_dist * w_dist) + (norm_rep * w_rep) + (norm_stock * w_stock)

                        ferreterias_ordenadas.append({
                            "id_ferreteria": f["id_ferreteria"],
                            "nombre": f["nombre"],
                            "direccion": f["direccion"],
                            "latitud": float(f["latitud"]),

                            "precio_bob": float(f["precio_bob"]),
                            "stock": int(f["stock_actual"]),
                            "reputacion": float(f["reputacion"]),
                            "distancia_km": round(float(f["distancia_km"]), 2),
                            "puntuacion_ahp": round(float(score_total), 4)
                        })

                    ferreterias_ordenadas.sort(key=lambda x: x["puntuacion_ahp"], reverse=True)
        finally:
            conn.close()

        return AHPResultadoOutput(

            es_consistente=res_math["es_consistente"],
            mensaje_consistencia=res_math["mensaje_consistencia"],
            ferreterias=ferreterias_ordenadas
        )
    except ValueError as err:

# app/modules/buscador_ahp/engine.py
# Motor algebraico con NumPy para la toma de decisiones multicriterio AHP.

import numpy as np
from typing import Dict, Any, List
from app.modules.buscador_ahp.schemas import AHPMatrizCriteriosInput

# Tabla de Índices Aleatorios (RI) de Saaty para matrices de tamaño n=1 a 10
TABLA_RI = {
    1: 0.00,
    2: 0.00,
    3: 0.58,
    4: 0.90,
    5: 1.12,
    6: 1.24,
    7: 1.32,
    8: 1.41,
    9: 1.45,
    10: 1.49
}


def calcular_proceso_ahp(datos: AHPMatrizCriteriosInput) -> Dict[str, Any]:
    criterios = datos.criterios
    n = len(criterios)
    A = np.array(datos.matriz_comparacion, dtype=float)

    # 1. Normalización por columnas: N[i, j] = A[i, j] / sum(A[:, j])
    suma_columnas = np.sum(A, axis=0)
    matriz_normalizada = A / suma_columnas

    # 2. Vector de Pesos / Prioridades (W): Promedio por fila de la matriz normalizada
    W = np.mean(matriz_normalizada, axis=1)

    # 3. Cálculo de A * W
    A_w = np.dot(A, W)

    # 4. Cálculo de lambda_max = Promedio( (A * W) / W )
    ratios_lambda = A_w / W
    lambda_max = float(np.mean(ratios_lambda))

    # 5. Índice de Consistencia CI = (lambda_max - n) / (n - 1)
    if n > 1:
        CI = (lambda_max - n) / (n - 1)
    else:
        CI = 0.0

    # 6. Índice Aleatorio RI según el tamaño n
    RI = TABLA_RI.get(n, 1.49)

    # 7. Ratio de Consistencia CR = CI / RI
    if RI > 0:
        CR = CI / RI
    else:
        CR = 0.0

    es_consistente = bool(CR < 0.10)

    # Formatear el vector de pesos a diccionario
    dict_pesos_W = {
        criterio: round(float(W[i] * 100.0), 2)
        for i, criterio in enumerate(criterios)
    }

    # 8. Evaluación de alternativas (si se enviaron)
    ranking = None
    if datos.alternativas:
        ranking_evaluado = []
        for alt in datos.alternativas:
            nombre = alt.get("nombre", "Ferretería Desconocida")
            score_total = 0.0
            
            for i, crit in enumerate(criterios):
                score_criterio = alt.get(crit, 0.0)
                score_total += score_criterio * W[i]

            ranking_evaluado.append({
                "nombre": nombre,
                "puntuacion_ponderada": round(float(score_total), 4),
                "detalles": alt
            })

        # Ordenar de mayor a menor puntuación
        ranking = sorted(ranking_evaluado, key=lambda x: x["puntuacion_ponderada"], reverse=True)

    # Mensaje explícito de consistencia
    if es_consistente:
        mensaje = (
            f"Matriz AHP consistente (CR = {round(CR, 4)} < 0.10). "
            f"Los pesos asignados son válidos para la toma de decisiones."
        )
    else:
        mensaje = (
            f"Advertencia: Matriz AHP inconsistente (CR = {round(CR, 4)} >= 0.10). "
            f"Existen juicios contradictorios. Por favor revise las comparaciones entre criterios."
        )

    return {
        "vector_pesos_W": dict_pesos_W,
        "lambda_maximo": round(lambda_max, 4),
        "indice_consistencia_CI": round(CI, 4),
        "indice_aleatorio_RI": round(RI, 2),
        "ratio_consistencia_CR": round(CR, 4),
        "es_consistente": es_consistente,
        "ranking_alternativas": ranking,
        "mensaje_consistencia": mensaje
    }

# app/modules/inventarios_eoq/engine.py
# Motor de cálculo determinístico de inventarios (EOQ Básico, EPQ, EOQ con Faltantes y ROP).

import math
from typing import Dict, Any
from app.modules.inventarios_eoq.schemas import EOQParametrosInput


def calcular_modelo_inventario(datos: EOQParametrosInput) -> Dict[str, Any]:
    """
    Selecciona y ejecuta dinámicamente el modelo de inventario correspondiente
    según los parámetros proporcionados:
      - EPQ: Si existe tasa_produccion_anual_P
      - EOQ con Faltantes: Si existe costo_faltante_p
      - EOQ Básico: Si no hay producción ni faltantes
    """
    # -------------------------------------------------------------------------
    # 1. EXTRACCIÓN DE PARÁMETROS NORMALIZADOS (ESCALA ANUAL)
    # -------------------------------------------------------------------------
    D = datos.demanda_anual_D or (datos.demanda_D * 1.0)
    H = datos.costo_mantenimiento_anual_H or (datos.costo_mantenimiento_H * 1.0)
    K = datos.costo_pedido_K
    C = datos.costo_unitario_C
    L_dias = datos.tiempo_entrega_dias_L
    dias_ano = datos.dias_laborales_ano
    SS = datos.stock_seguridad_SS

    if D <= 0 or H <= 0 or K <= 0:
        raise ValueError("La demanda (D), el costo de pedido (K) y el costo de mantenimiento (H) deben ser mayores a cero.")

    # Demanda diaria (d)
    d_diaria = D / float(dias_ano)

    # -------------------------------------------------------------------------
    # 2. IDENTIFICACIÓN Y CÁLCULO DEL MODELO CORRESPONDIENTE
    # -------------------------------------------------------------------------
    deficit_maximo_S = None
    inventario_maximo_Imax = None

    # CASO A: Modelo de Lote Económico de Producción (EPQ)
    if datos.tasa_produccion_anual_P is not None:
        P = datos.tasa_produccion_anual_P
        if P <= D:
            raise ValueError("En el modelo EPQ, la tasa de producción (P) debe ser mayor a la demanda (D).")
        
        modelo_nombre = "Lote Económico de Producción (EPQ)"
        # Q* = sqrt( (2 * D * K) / ( H * (1 - D/P) ) )
        factor_produccion = 1.0 - (D / P)
        lote_optimo_Q = math.sqrt((2.0 * D * K) / (H * factor_produccion))
        
        inventario_maximo_Imax = lote_optimo_Q * factor_produccion
        costo_mant_anual = (inventario_maximo_Imax / 2.0) * H
        costo_faltante_anual = 0.0

    # CASO B: Modelo EOQ con Faltantes / Déficit Permitido
    elif datos.costo_faltante_p is not None:
        # En la sección de EOQ con Faltantes de engine.py
        p_anual = datos.costo_faltante_anual_p if datos.costo_faltante_anual_p is not None else datos.costo_faltante_p
        if p_anual <= 0:
            raise ValueError("El costo de penalización por faltante (p) debe ser mayor a cero.")
        
        modelo_nombre = "EOQ con Faltantes Permitidos"
        # Q* = sqrt( ((2*D*K)/H) * ((p + H)/p) )
        lote_optimo_Q = math.sqrt(((2.0 * D * K) / H) * ((p_anual + H) / p_anual))
        
        # S* = Q* * (H / (p + H))
        deficit_maximo_S = lote_optimo_Q * (H / (p_anual + H))
        inventario_maximo_Imax = lote_optimo_Q - deficit_maximo_S
        
        costo_mant_anual = ((inventario_maximo_Imax ** 2) / (2.0 * lote_optimo_Q)) * H
        costo_faltante_anual = ((deficit_maximo_S ** 2) / (2.0 * lote_optimo_Q)) * p_anual

    # CASO C: Modelo EOQ Básico Clásico
    else:
        modelo_nombre = "Lote Económico de Pedido (EOQ Básico)"
        # Q* = sqrt( (2 * D * K) / H )
        lote_optimo_Q = math.sqrt((2.0 * D * K) / H)
        inventario_maximo_Imax = lote_optimo_Q
        
        costo_mant_anual = (lote_optimo_Q / 2.0) * H
        costo_faltante_anual = 0.0

    # -------------------------------------------------------------------------
    # 3. MÉTRICAS COMPLEMENTARIAS Y COSTOS TOTALES
    # -------------------------------------------------------------------------
    # Punto de Reorden ROP = (d * L) + SS
    rop = (d_diaria * float(L_dias)) + float(SS)

    # Número de pedidos/corridas al año N = D / Q*
    pedidos_ano_N = D / lote_optimo_Q

    # Tiempo entre pedidos T (días) = dias_laborales / N
    tiempo_entre_pedidos_T = float(dias_ano) / pedidos_ano_N

    # Costo de ordenar/preparar al año = N * K
    costo_pedido_anual = pedidos_ano_N * K

    # Costo de adquisición directo = D * C
    costo_adquisicion_anual = D * C

    # Costo Total de Gestión de Inventario CT
    costo_total_CT = costo_pedido_anual + costo_mant_anual + costo_faltante_anual + costo_adquisicion_anual

    # -------------------------------------------------------------------------
    # 4. ESTRUCTURA DE RETORNO NATIVA (Coincide con EOQResultadoOutput)
    # -------------------------------------------------------------------------
    return {
        "modelo_aplicado": modelo_nombre,
        "lote_optimo_Q": round(lote_optimo_Q, 2),
        "punto_reorden_ROP": round(rop, 2),
        "pedidos_por_ano_N": round(pedidos_ano_N, 2),
        "tiempo_entre_pedidos_T_dias": round(tiempo_entre_pedidos_T, 1),
        "costo_pedido_anual": round(costo_pedido_anual, 2),
        "costo_mantenimiento_anual": round(costo_mant_anual, 2),
        "costo_total_inventario_CT": round(costo_total_CT, 2),
        "deficit_maximo_S": round(deficit_maximo_S, 2) if deficit_maximo_S is not None else None,
        "inventario_maximo_Imax": round(inventario_maximo_Imax, 2) if inventario_maximo_Imax is not None else None,
    }

    costo_unitario_C: float = Field(default=0.0, ge=0, description="Costo de adquisición por unidad (BOB)")
    tiempo_entrega_dias_L: int = Field(default=5, ge=0, description="Tiempo de espera del proveedor L (días)")
    dias_laborales_ano: int = Field(default=300, gt=0, description="Días operativos de la ferretería al año")
    stock_seguridad_SS: int = Field(default=0, ge=0, description="Stock de seguridad requerido")
    
    # Parámetros opcionales para EPQ (Producción propia)
    tasa_produccion_P: Optional[float] = Field(default=None, description="Tasa de producción en la misma unidad de tiempo (para EPQ)")
    
    # Parámetros opcionales para EOQ con Faltantes

    # Campos calculados internamente para el motor
    demanda_anual_D: Optional[float] = None
    tasa_produccion_anual_P: Optional[float] = None
    costo_mantenimiento_anual_H: Optional[float] = None
    costo_faltante_anual_p: Optional[float] = None

    @model_validator(mode="after")
    def validar_y_normalizar(self) -> "EOQParametrosInput":

        if self.tasa_produccion_P is not None and self.tasa_produccion_P <= self.demanda_D:

            )

        # 2. Normalización automática a escala anual
        factor = 1.0
        if self.unidad_tiempo == "Meses":
            factor = 12.0
        elif self.unidad_tiempo == "Días":
            factor = float(self.dias_laborales_ano)

        self.costo_mantenimiento_anual_H = self.costo_mantenimiento_H * factor
        
        if self.tasa_produccion_P is not None:
            self.tasa_produccion_anual_P = self.tasa_produccion_P * factor

        if self.costo_faltante_p is not None:
            self.costo_faltante_anual_p = self.costo_faltante_p * factor
            
        return self

# app/modules/decisiones/engine.py
# Motor algebraico con NumPy para Teoría de Decisión (Incertidumbre y Riesgo).

import numpy as np
from typing import Dict, Any
from app.modules.decisiones.schemas import DecisionInput


def evaluar_toma_decisiones(datos: DecisionInput) -> Dict[str, Any]:
    """
    Resuelve los 5 criterios bajo Incertidumbre (Laplace, Wald Optimista/Pesimista, Hurwicz, Savage)
    y opcionalmente los criterios bajo Riesgo (VME, VEconIP, VEIP).
    """
    alts = datos.alternativas
    estados = datos.estados_naturaleza
    matriz_A = np.array(datos.matriz_pagos, dtype=float)  # Dimensión: (num_alts, num_estados)
    alpha = datos.coeficiente_alpha

    num_alts, num_estados = matriz_A.shape

    # -------------------------------------------------------------------------
    # 1. CRITERIOS BAJO INCERTIDUMBRE
    # -------------------------------------------------------------------------
    
    # A) LAPLACE: Promedio por fila (asume equiprobabilidad 1/n)
    v_laplace = np.mean(matriz_A, axis=1)
    idx_laplace = int(np.argmax(v_laplace))
    
    # B) WALD OPTIMISTA (MaxiMax): El máximo de los máximos por fila
    maximos_fila = np.max(matriz_A, axis=1)
    idx_optimista = int(np.argmax(maximos_fila))
    
    # C) WALD PESIMISTA (MaxiMin): El máximo de los mínimos por fila
    minimos_fila = np.min(matriz_A, axis=1)
    idx_pesimista = int(np.argmax(minimos_fila))
    
    # D) HURWICZ: alpha * Max + (1 - alpha) * Min
    v_hurwicz = (alpha * maximos_fila) + ((1.0 - alpha) * minimos_fila)
    idx_hurwicz = int(np.argmax(v_hurwicz))
    
    # E) SAVAGE (Arrepentimiento / Pérdida de Oportunidad):
    #     R_ij = Max_coluna_j - A_ij
    maximos_columna = np.max(matriz_A, axis=0)  # Valor máximo alcanzable en cada estado
    matriz_savage = maximos_columna - matriz_A   # Matriz de lamento (>= 0)
    
    lamento_maximo_fila = np.max(matriz_savage, axis=1)  # Peor arrepentimiento posible por alternativa
    idx_savage = int(np.argmin(lamento_maximo_fila))     # Criterio MiniMax: Elegir el menor lamento máximo
    
    # Formatear la tabla Savage para el retorno
    dict_savage_tabla = {}
    for i, alt in enumerate(alts):
        dict_savage_tabla[alt] = {}
        for j, est in enumerate(estados):
            dict_savage_tabla[alt][est] = round(float(matriz_savage[i, j]), 2)

    criterios_incertidumbre = {
        "Laplace (Equiprobabilidad)": {
            "alternativa_optima": alts[idx_laplace],
            "valor_obtenido": round(float(v_laplace[idx_laplace]), 2)
        },
        "Wald Optimista (MaxiMax)": {
            "alternativa_optima": alts[idx_optimista],
            "valor_obtenido": round(float(maximos_fila[idx_optimista]), 2)
        },
        "Wald Pesimista (MaxiMin)": {
            "alternativa_optima": alts[idx_pesimista],
            "valor_obtenido": round(float(minimos_fila[idx_pesimista]), 2)
        },
        f"Hurwicz (alpha={alpha})": {
            "alternativa_optima": alts[idx_hurwicz],
            "valor_obtenido": round(float(v_hurwicz[idx_hurwicz]), 2)
        },
        "Savage (MiniMax Arrepentimiento)": {
            "alternativa_optima": alts[idx_savage],
            "valor_obtenido": round(float(lamento_maximo_fila[idx_savage]), 2)
        }
    }

    # -------------------------------------------------------------------------
    # 2. CRITERIOS BAJO RIESGO (Si se proporcionan probabilidades P_j)
    # -------------------------------------------------------------------------
    analisis_riesgo = None
    if datos.probabilidades is not None:
        P = np.array(datos.probabilidades, dtype=float)
        
        # VME_i = sum_j ( P_j * A_ij )  -> Multiplicación Matriz-Vector
        vector_vme = np.dot(matriz_A, P)
        idx_vme_opt = int(np.argmax(vector_vme))
        vme_optimo = float(vector_vme[idx_vme_opt])
        
        # VEconIP = sum_j ( P_j * Max_i(A_ij) )  -> Valor Esperado Con Información Perfecta
        ve_con_ip = float(np.sum(P * maximos_columna))
        
        # VEIP = VEconIP - VME_optimo  -> Valor Esperado de la Información Perfecta
        veip = ve_con_ip - vme_optimo
        
        dict_vme_alts = {
            alts[i]: round(float(vector_vme[i]), 2)
            for i in range(num_alts)
        }
        
        analisis_riesgo = {
            "vme_por_alternativa": dict_vme_alts,
            "decision_optima_vme": alts[idx_vme_opt],
            "vme_optimo": round(vme_optimo, 2),
            "ve_con_ip": round(ve_con_ip, 2),
            "veip": round(veip, 2)
        }

    # -------------------------------------------------------------------------
    # 3. RECOMENDACIÓN GENERAL COMPRENSIBLE
    # -------------------------------------------------------------------------
    if analisis_riesgo:
        rec = (
            f"Bajo condiciones de riesgo, se recomienda la alternativa '{analisis_riesgo['decision_optima_vme']}' "
            f"con un VME de {analisis_riesgo['vme_optimo']} BOB. El Valor Esperado de la Información Perfecta (VEIP) "
            f"es de {analisis_riesgo['veip']} BOB (móntulo máximo a pagar por un estudio de mercado)."
        )
    else:
        rec = (
            f"Bajo incertidumbre, el criterio Pesimista (Wald) sugiere '{alts[idx_pesimista]}', "
            f"mientras que Laplace recomienda '{alts[idx_laplace]}'. Savage minimiza el lamento en '{alts[idx_savage]}'."
        )

    return {
        "criterios_incertidumbre": criterios_incertidumbre,
        "matriz_savage_arrepentimiento": dict_savage_tabla,
        "analisis_riesgo": analisis_riesgo,
        "recomendacion_general": rec
    }

        description="Escenarios o estados de la naturaleza posibles"
    )
    matriz_pagos: List[List[float]] = Field(
        ...,
        description="Matriz de beneficios/pagos A (filas = alternativas, columnas = estados)"
    )
    probabilidades: Optional[List[float]] = Field(
        default=None,
        description="Probabilidades Pj de cada estado para decisiones bajo riesgo (opcional)"
    )
    coeficiente_alpha: float = Field(
        default=0.7, 
        ge=0.0, 
        le=1.0, 
        description="Coeficiente de optimismo alpha para Hurwicz"
    )

    @field_validator("matriz_pagos")
    @classmethod
    def validar_dimensiones_matriz(cls, v: List[List[float]], info) -> List[List[float]]:
        if not v or not v[0]:
            raise ValueError("La matriz de pagos no puede estar vacía.")

        alternativas = info.data.get("alternativas")
        estados = info.data.get("estados_naturaleza")

        if alternativas and len(v) != len(alternativas):
            raise ValueError(
                f"La matriz de pagos tiene {len(v)} filas, pero se definieron {len(alternativas)} alternativas."
            )

        if estados:
            num_cols = len(estados)
            for i, fila in enumerate(v):
                if len(fila) != num_cols:
                    raise ValueError(
                        f"La fila {i} de la matriz tiene {len(fila)} columnas, pero hay {num_cols} estados de la naturaleza."
                    )
        return v

    @model_validator(mode="after")
    def validar_consistencia_decision(self) -> "DecisionInput":
        if len(set(self.alternativas)) != len(self.alternativas):
            raise ValueError("No puede haber nombres de alternativas duplicadas.")
        if len(set(self.estados_naturaleza)) != len(self.estados_naturaleza):
            raise ValueError("No puede haber nombres de estados de la naturaleza duplicados.")

        if self.probabilidades is not None:
            num_estados = len(self.estados_naturaleza)
            if len(self.probabilidades) != num_estados:
                raise ValueError(
                    f"Se enviaron {len(self.probabilidades)} probabilidades, pero hay {num_estados} estados de la naturaleza."
                )

            for p in self.probabilidades:
                if p < 0.0 or p > 1.0:
                    raise ValueError(f"La probabilidad {p} debe estar entre 0.0 y 1.0.")

            suma_p = sum(self.probabilidades)
            if abs(suma_p - 1.0) > 1e-4:
                raise ValueError(f"La suma de las probabilidades debe ser exactamente 1.0 (suma actual: {suma_p:.4f}).")

        return self

# app/modules/markov/engine.py
# Motor de cálculo algebraico puro con NumPy para Cadenas de Markov Absorbentes.

#Mantenibilidad (Si algo se rompe):
#Si la respuesta JSON de la API no coincide con la documentación 
#   entonces Revisas el diccionario de retorno en engine.py 
# o el modelo en schemas.py.Si da error en la multiplicación o inversión matricial 
#   entonces Ajustas las dimensiones 
# o la conversión a NumPy en engine.py.   
# Si la ruta HTTP falla o no responde 
#   entonces Revisas routes.py.


import numpy as np
from typing import Dict, Any, List


def calcular_cadena_markov_absorbente(
    estados_trans: List[str],
    estados_abs: List[str],
    matriz_Q_raw: List[List[float]],
    matriz_R_raw: List[List[float]]
) -> Dict[str, Any]:
    """
    Ejecuta el álgebra de estados absorbentes usando la forma canónica P = [[Q, R], [0, I]].
    
    Fórmulas:
      1. Matriz Fundamental: N = (I - Q)^-1
      2. Matriz de Absorción: B = N * R
      3. Tiempo/Pasos hasta absorción: t = N * vector_unos
    """
    Q = np.array(matriz_Q_raw, dtype=float)
    R = np.array(matriz_R_raw, dtype=float)
    
    k = Q.shape[0]  # Cantidad de estados transitorios (filas/columnas de Q)
    r = R.shape[1]  # Cantidad de estados absorbentes (columnas de R)
    
    # -------------------------------------------------------------------------
    # VALIDACIÓN DE DIMENSIONES INTERNAS (Defensa contra desalineación)
    # -------------------------------------------------------------------------
    if len(estados_trans) != k:
        raise ValueError(f"Se recibieron {len(estados_trans)} nombres de estados transitorios, pero la matriz Q tiene {k} filas.")
    
    if R.shape[0] != k:
        raise ValueError(f"La matriz R debe tener {k} filas (igual a Q), pero tiene {R.shape[0]}.")
        
    if len(estados_abs) != r:
        raise ValueError(f"Se recibieron {len(estados_abs)} nombres de estados absorbentes, pero la matriz R tiene {r} columnas.")

    # 1. Matriz Identidad I de tamaño (k x k)
    I = np.eye(k)
    
    # 2. Matriz Fundamental: N = (I - Q)^-1
    I_minus_Q = I - Q
    try:
        N = np.linalg.inv(I_minus_Q)
    except np.linalg.LinAlgError:
        raise ValueError(
            "La matriz (I - Q) es singular y no se puede invertir. "
            "Verifique que las probabilidades de Q permitan salir hacia estados absorbentes."
        )
    
    # 3. Matriz de Absorción: B = N * R
    B = np.matmul(N, R)
    
    # 4. Pasos promedio esperados antes de la absorción: t = N * vector_unos
    t = np.sum(N, axis=1)
    
    # -------------------------------------------------------------------------
    # CONVERSIÓN A TIPOS NATIVOS DE PYTHON (Listas y Diccionarios)
    # -------------------------------------------------------------------------
    matriz_N_list = np.round(N, 4).tolist()
    
    dict_B = {}
    for i, origen in enumerate(estados_trans):
        dict_B[origen] = {}
        for j, destino in enumerate(estados_abs):
            dict_B[origen][destino] = round(float(B[i, j]), 4)
            
    dict_t = {
        origen: round(float(t[i]), 2)
        for i, origen in enumerate(estados_trans)
    }
    
    # -------------------------------------------------------------------------
    # GENERACIÓN DINÁMICA DE INTERPRETACIONAL HUMANA (Sin hardcodear B[i, 0])
    # -------------------------------------------------------------------------
    interpretaciones = []
    for i, origen in enumerate(estados_trans):
        pasos = dict_t[origen]
        
        # Iteramos sobre TODOS los estados absorbentes reales sin asumir cuál es el primero
        desglose = [
            f"{round(float(B[i, j]) * 100, 1)}% en '{destino}'"
            for j, destino in enumerate(estados_abs)
        ]
        texto_desglose = ", ".join(desglose)
        
        interpretaciones.append(
            f"Un usuario que inicia en '{origen}' realiza en promedio {pasos} interacciones "
            f"y sus probabilidades finales son: {texto_desglose}."
        )
        
    return {
        "matriz_fundamental_N": matriz_N_list,
        "matriz_absorcion_B": dict_B,
        "pasos_esperados_t": dict_t,
        "interpretacion_humana": interpretaciones
    }

from typing import List, Dict
from pydantic import BaseModel, Field, field_validator, model_validator

# -------------------------------------------------------------------------
# 1. FUNCIÓN AUXILIAR DE VALIDACIÓN MATEMÁTICA
# -------------------------------------------------------------------------
def validar_rango_probabilidades(matriz: List[List[float]], nombre_matriz: str) -> None:
    """Revisa que todos los números dentro de la matriz 
       estén entre 0.0 y 1.0."""
    if not matriz:
        raise ValueError(f"La {nombre_matriz} no puede estar vacía.")

    for num_fila, fila in enumerate(matriz):
        for valor in fila:
            if valor < 0.0 or valor > 1.0:
                raise ValueError(
                    f"En {nombre_matriz} (fila {num_fila}), el valor {valor} no es una probabilidad válida (debe estar entre 0.0 y 1.0)."
                )

# -------------------------------------------------------------------------
# 2. MODELO DE ENTRADA (LO QUE EL CLIENTE O EL FRONTEND ENVÍA)
# -------------------------------------------------------------------------
class MarkovMatrixInput(BaseModel):
    #El molde recibe los datos de entrada cuando el cliente 
    # hace un POST a la ruta /api/markov/simular, y valida que cumplan 
    # con las condiciones de la clase MarkovMatrixInput
    estados_transitorios: List[str] = Field(
        default=["Busqueda", "VistaProducto", "EnCarrito"],
        description="Nombres de los estados no finales de la aplicación"
    )
    estados_absorbentes: List[str] = Field(
        default=["CompraRealizada", "Abandono"],
        description="Nombres de los estados finales (absorbentes)"
    )
    matriz_Q: List[List[float]] = Field(
        ...,
        description="Matriz Q (k x k): probabilidades entre estados transitorios"
    )
    matriz_R: List[List[float]] = Field(
        ...,
        description="Matriz R (k x r): probabilidades hacia estados absorbentes"
    )
    # VALIDADOR 1: Matriz Q debe ser cuadrada y sus números entre 0 y 1
    @field_validator("matriz_Q") #Nada más reciba el atributo de matriz_Q anteriormente declarado, se ejecuta esta función para validar su contenido

    # Eso hace field_validator, que es un decorador de Pydantic 
    # que permite definir validaciones personalizadas para los campos 
    # de un modelo. En este caso, se está aplicando a la propiedad matriz_Q 
    # del modelo MarkovMatrixInput.

    @classmethod
    def validar_matriz_Q(cls, v: List[List[float]]) -> List[List[float]]:
        validar_rango_probabilidades(v, "matriz_Q")
        k = len(v)
        for num_fila, fila in enumerate(v):
            if len(fila) != k:
                raise ValueError(f"La matriz Q debe ser cuadrada ({k}x{k}). La fila {num_fila} tiene {len(fila)} elementos.")
        return v
    # VALIDADOR 2: Matriz R debe tener tantas filas como Q y números entre 0 y 1
    @field_validator("matriz_R")
    @classmethod
    def validar_matriz_R(cls, v: List[List[float]], info) -> List[List[float]]:
        validar_rango_probabilidades(v, "matriz_R")
        matriz_Q = info.data.get("matriz_Q")
        if matriz_Q and len(v) != len(matriz_Q):
            raise ValueError(f"La matriz R debe tener {len(matriz_Q)} filas (igual que Q), pero tiene {len(v)}.")
        return v
    # VALIDADOR 3: Comprobación global (Suma de cada fila Q + R debe ser 1.0)
    @model_validator(mode="after")
    def validar_consistencia_global(self) -> "MarkovMatrixInput":
        # 1. Validar que no existan nombres duplicados
        if len(set(self.estados_transitorios)) != len(self.estados_transitorios):
            raise ValueError("Los nombres de los estados transitorios no pueden estar duplicados.")
        if len(set(self.estados_absorbentes)) != len(self.estados_absorbentes):
            raise ValueError("Los nombres de los estados absorbentes no pueden estar duplicados.")

        # 2. Validar coincidencia exacta de nombres vs dimensiones (evita IndexError)
        if len(self.estados_transitorios) != len(self.matriz_Q):
            raise ValueError(
                f"La cantidad de estados transitorios ({len(self.estados_transitorios)}) "
                f"no coincide con las filas de Q ({len(self.matriz_Q)})."
            )
        if len(self.matriz_R) > 0 and len(self.estados_absorbentes) != len(self.matriz_R[0]):
            raise ValueError(
                f"La cantidad de estados absorbentes ({len(self.estados_absorbentes)}) "
                f"no coincide con las columnas de R ({len(self.matriz_R[0])})."
            )

        # 3. Validar suma estocástica por fila (Q + R = 1.0)
        for i in range(len(self.matriz_Q)):
            suma_q = sum(self.matriz_Q[i])
            suma_r = sum(self.matriz_R[i])
            suma_total = suma_q + suma_r
            if abs(suma_total - 1.0) > 1e-5:
                raise ValueError(
                    f"Error en fila {i} ({self.estados_transitorios[i]}): "
                    f"La suma Q + R es {suma_total:.4f}, pero DEBE ser 1.0."
                )
        return self

# app/modules/colas_mm1/engine.py
# Motor de cálculo determinístico para Teoría de Colas M/M/1.

from typing import Dict, Any
from app.modules.colas_mm1.schemas import ColasMM1Input


def calcular_colas_mm1(datos: ColasMM1Input) -> Dict[str, Any]:
    lam = datos.tasa_llegada_lambda
    mu = datos.tasa_servicio_mu
    unidad = datos.unidad_tiempo.lower().strip()

    factor_a_minutos = 60.0 if unidad == "horas" else 1.0

    rho = lam / mu
    P0 = 1.0 - rho
    Ls = lam / (mu - lam)
    Lq = (lam ** 2) / (mu * (mu - lam))
    
    Ws_raw = 1.0 / (mu - lam)
    Ws_min = Ws_raw * factor_a_minutos

    Wq_raw = lam / (mu * (mu - lam))
    Wq_min = Wq_raw * factor_a_minutos

    W_servicio_min = (1.0 / mu) * factor_a_minutos

    probabilidades_Pn = {}
    for n in range(6):
        Pn = (1.0 - rho) * (rho ** n)
        probabilidades_Pn[f"P_{n}_clientes"] = round(float(Pn * 100.0), 2)

    if Wq_min > 15.0:
        rec = (
            f"Alta congestión: Se estima una espera en cola (Wq) de {round(Wq_min, 1)} min "
            f"y un tiempo total de estancia (Ws) de {round(Ws_min, 1)} min. "
            f"Probabilidad de ser atendido sin fila (P0): {round(P0 * 100, 1)}%."
        )
    elif Wq_min > 5.0:
        rec = (
            f"Congestión moderada: Tiempo en cola (Wq) de {round(Wq_min, 1)} min. "
            f"Tiempo de estancia estimado: {round(Ws_min, 1)} min."
        )
    else:
        rec = (
            f"Atención fluida: Solo {round(Wq_min, 1)} min en cola (Wq). "
            f"Tienes un {round(P0 * 100, 1)}% de probabilidad de ser atendido de inmediato."
        )

    # Claves exactas requeridas por ColasMM1Output
    return {
        "factor_uso_rho": round(float(rho), 4),
        "probabilidad_sistema_vacio_P0_pct": round(float(P0 * 100.0), 2),
        "clientes_en_sistema_Ls": round(float(Ls), 2),
        "clientes_en_cola_Lq": round(float(Lq), 2),
        "tiempo_espera_cola_Wq": round(float(Wq_raw), 4),
        "tiempo_atencion_caja_minutos": round(float(W_servicio_min), 2),
        "tiempo_total_sistema_Ws_minutos": round(float(Ws_min), 2),
        "probabilidades_estado_estacionario": probabilidades_Pn,
        "recomendacion_cliente": rec
    }

# Validaciones para el modelo de colas M/M/1.

from typing import Dict
from pydantic import BaseModel, Field, model_validator


class ColasMM1Input(BaseModel):
    tasa_llegada_lambda: float = Field(
        ..., 
        gt=0.0, 
        description="Tasa promedio de llegada de clientes lambda"
    )
    tasa_servicio_mu: float = Field(
        ..., 
        gt=0.0, 
        description="Tasa promedio de atención mu"
    )
    unidad_tiempo: str = Field(
        default="horas", 
        description="Unidad de tiempo ('horas' o 'minutos')"
    )

    @model_validator(mode="after")
    def validar_estabilidad_sistema(self) -> "ColasMM1Input":
        if self.tasa_servicio_mu <= self.tasa_llegada_lambda:
            raise ValueError(
                f"El sistema es inestable (cola infinita). La tasa de atención mu ({self.tasa_servicio_mu}) "
                f"debe ser estrictamente mayor que la de llegada lambda ({self.tasa_llegada_lambda})."
            )
        return self


class ColasMM1Output(BaseModel):
    factor_uso_rho: float = Field(..., description="Porcentaje de tiempo que el servicio está ocupado")
    probabilidad_sistema_vacio_P0_pct: float = Field(..., description="Probabilidad de ser atendido inmediatamente")

    tiempo_atencion_caja_minutos: float = Field(..., description="Tiempo promedio de cobro en ventanilla")

        return String(texto)
            .replace(/&/g, '&amp;')
            .replace(/</g, '&lt;')
            .replace(/>/g, '&gt;')
            .replace(/"/g, '&quot;')
            .replace(/'/g, '&#39;');
    };

    const getAuthHeaders = (conJson = false) => {
        const headers = {};
        if (conJson) headers['Content-Type'] = 'application/json';
        const token = localStorage.getItem('iop812-token');
        if (token) headers['Authorization'] = `Bearer ${token}`;
        return headers;
    };

    // Helper para notificaciones con SweetAlert2
    const notificar = (titulo, texto, icono = 'info') => {
        // Quitar el foco de cualquier elemento activo para evitar advertencias aria-hidden
        if (document.activeElement && typeof document.activeElement.blur === 'function') {
            document.activeElement.blur();
        }
        const esOscuro = document.documentElement.getAttribute('data-theme') !== 'light';
        return Swal.fire({
            title: titulo,
            text: texto,
            icon: icono,
            background: esOscuro ? '#1E293B' : '#FFFFFF',
            color: esOscuro ? '#F8FAFC' : '#0F172A',
            confirmButtonColor: icono === 'error' ? '#EF4444' : '#0EA5E9',
            customClass: { popup: 'rounded-4 border border-secondary-subtle shadow-lg' }
        });
    };

    // ---------------------------------------------------------------
    // 2. TEMA OSCURO / CLARO
    // ---------------------------------------------------------------
    const themeToggleBtn = document.getElementById('themeToggle');
    const themeIcon = document.getElementById('themeIcon');

    const aplicarTema = (tema) => {
        document.documentElement.setAttribute('data-theme', tema);
        localStorage.setItem('iop812-theme', tema);
        if (themeIcon) {
            themeIcon.className = tema === 'light' ? 'fa-solid fa-sun text-warning' : 'fa-solid fa-moon text-light';
        }
    };
    aplicarTema(localStorage.getItem('iop812-theme') || 'dark');

    themeToggleBtn?.addEventListener('click', () => {

        aplicarTema(temaActual === 'dark' ? 'light' : 'dark');

                markersLayer.removeLayer(layer);

    const procesarRetornoOAuth = async () => {
        const hashParams = new URLSearchParams(window.location.hash.replace(/^#/, ''));
        const queryParams = new URLSearchParams(window.location.search);
        const oauthToken = hashParams.get('access_token');
        const oauthError = queryParams.get('auth_error');

        if (oauthToken) {
            localStorage.setItem('iop812-token', oauthToken);
            window.history.replaceState({}, document.title, window.location.pathname);
            try {
                const perfil = await obtenerPerfil(oauthToken);
                actualizarInterfazSesion(perfil);
                notificar('Acceso Correcto', `Bienvenido ${perfil.username} (${perfil.rol.toUpperCase()}).`, 'success');
                return true;
            } catch (err) {
                localStorage.removeItem('iop812-token');
            }
        } else if (oauthError) {
            window.history.replaceState({}, document.title, window.location.pathname);
            const mensajesError = {
                google_not_configured: 'Faltan GOOGLE_CLIENT_ID o GOOGLE_CLIENT_SECRET en el archivo .env del servidor.',
                invalid_state: 'La sesión de seguridad OAuth expiró. Intenta iniciar sesión nuevamente.',
                access_denied: 'Cancelaste el inicio de sesión con Google.',
                google_token_exchange_failed: 'No se pudo validar el código con Google. Verifica el Redirect URI en Google Cloud Console.'
            };
            notificar('Inicio con Google', mensajesError[oauthError] || `Error OAuth2: ${oauthError}`, 'warning');
        }
        return false;
    };

# app/shared/database.py
# Gestión de conexiones PostgreSQL/PostGIS e inicialización limpia del esquema.

import os
import logging
import psycopg2
from psycopg2.extras import RealDictCursor
from dotenv import load_dotenv

load_dotenv()
logger = logging.getLogger(__name__)


def obtener_conexion():
    """
    Abre una conexión a PostgreSQL utilizando DATABASE_URL (Render/Nube)
    o las variables individuales del archivo .env local, devolviendo filas como diccionarios.
    """
    database_url = os.getenv("DATABASE_URL", "").strip()

    if database_url:
        # Render a veces entrega 'postgres://' y psycopg2 requiere 'postgresql://'
        if database_url.startswith("postgres://"):
            database_url = database_url.replace("postgres://", "postgresql://", 1)
        return psycopg2.connect(database_url, cursor_factory=RealDictCursor)

    return psycopg2.connect(
        host=os.getenv("DB_HOST", "localhost"),
        port=os.getenv("DB_PORT", "5432"),
        dbname=os.getenv("DB_NAME", "iop812_db"),
        user=os.getenv("DB_USER", "postgres"),
        password=os.getenv("DB_PASSWORD", ""),
        cursor_factory=RealDictCursor
    )


def inicializar_base_datos():
    """
    Ejecuta init_db.sql para garantizar la extensión PostGIS, las 11 tablas e índices,
    añade la columna 'rol' en usuarios y asigna permisos 'admin' al correo definido en
    ADMIN_EMAIL sin insertar datos ficticios.
    """
    conn = None
    try:
        conn = obtener_conexion()
        root_dir = os.path.abspath(os.path.join(os.path.dirname(__file__), "..", ".."))
        sql_path = os.path.join(root_dir, "init_db.sql")

        with conn.cursor() as cur:
            if os.path.exists(sql_path):
                with open(sql_path, "r", encoding="utf-8") as f:
                    cur.execute(f.read())
            else:
                logger.warning("No se encontró init_db.sql en %s", sql_path)

            cur.execute("""
                ALTER TABLE usuarios
                ADD COLUMN IF NOT EXISTS rol VARCHAR(20) DEFAULT 'cliente';
            """)

            raw_admins = os.getenv("ADMIN_EMAILS") or os.getenv("ADMIN_EMAIL") or ""
            admin_emails = [e.strip().lower() for e in raw_admins.split(",") if e.strip()]
            if admin_emails:
                cur.execute(
                    "UPDATE usuarios SET rol = 'admin' WHERE LOWER(email) = ANY(%s);",
                    (admin_emails,)
                )
                cur.execute(
                    """
                    UPDATE usuarios
                    SET rol = CASE
                        WHEN EXISTS (
                            SELECT 1 FROM ferreterias f WHERE f.id_usuario_propietario = usuarios.id_usuario
                        ) THEN 'ferretero'
                        ELSE 'cliente'
                    END
                    WHERE rol = 'admin' AND NOT (LOWER(email) = ANY(%s));
                    """,
                    (admin_emails,)
                )

            conn.commit()
            logger.info("Esquema PostgreSQL/PostGIS verificado correctamente (base limpia).")
    except Exception as e:
        if conn:
            conn.rollback()
        logger.error("Error al inicializar el esquema de base de datos: %s", e)
        raise
    finally:
        if conn:
            conn.close()
